# Historical collector (v5)

This folder is a snapshot of the supplied `SRS_campaign_v5_5loads_updated.tar.gz` archive. It is retained for research traceability. **Do not claim this is the exact code used in the final v6 run campaign until proven by the OAIBOX and UE experiment records.**

The protocol described in its README rotates load order across three repetitions. Its SRS-period configuration requires manual gNB source modification and restart between period blocks.
